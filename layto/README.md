# Layto 🇹🇳

- `avatar-transparent.png` — full-body, transparent (blouza outfit)
- `avatar-hoodie.png` — original hoodie avatar, transparent
- `profile.png` — circular profile, vivid background
- `poses/` — 6 transparent pose stickers (hello, excited, laughing, intro, celebrating, floss)
